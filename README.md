# 智曆記事本 (Smart Calendar & Notepad)

一套具備**農曆萬年曆**、**待做事件管理**、**提醒事項設定**與**到期日前一天特殊邊框警示**的現代化繁體中文網頁應用程式。

---

## 🌟 主要功能特點

### 1. 雙核心架構：待做事件 vs 提醒事項
- **📋 待做事件 (To-Do Tasks)**：
  - 設定**到期日 (Due Date)** 與指定時間。
  - 支援勾選完成/未完成狀態（完成自動劃線及半透明化）。
  - 支援多維度篩選：全部待辦、進行中、⚠️ 明日到期警示、今日到期、已逾期、已完成。
- **🔔 提醒事項 (Reminders)**：
  - 選擇**提醒日期 (Reminder Date)** 與提醒時間。
  - 支援篩選：全部提醒、今日提醒、即將到來、過去提醒。
- **🌐 全部視圖與即時搜尋**：
  - 整合頁籤可同時檢視待辦與提醒，即時關鍵字模糊搜尋標題與備註內容。

### 2. 完整萬年曆與農曆支援 (1900-2100)
- **純前端精準演算法**：完全內建於 `lunar.js`，無需任何第三方外部網路連線，離線即可使用。
- **詳細農曆資訊呈現**：
  - 每格月曆同步顯示陽曆日期（1~31）與對應農曆（如初四、十五，初一自動標註月份名如九月）。
  - **二十四節氣**（立春、清明、寒露、霜降、冬至等）以鮮明紅字標註。
  - **傳統節日**（春節、除夕、元宵、端午、中秋、重陽等）與常見公曆節日（元旦、國慶日、聖誕節等）自動標示。
  - 月曆標頭提供干支紀年與生肖（如【丙午 馬年 · 九月】）。
  - 支援月份/年份快速切換與「回到本月」功能。

### 3. 自行挑選專屬色彩 (Color Customization)
- 支援 **8 款精選預設色票**（經典藍、薄荷綠、活力橘、珊瑚紅、薰衣草紫、櫻花粉、蒂芙藍、石墨灰）。
- 支援 **原生自訂色彩盤 (`<input type="color">`)**，任意挑選百萬種 HEX 顏色。
- 事件放上月曆時，會以使用者挑選的專屬色彩呈現彩色膠囊標籤，並自動依色彩深淺切換最適對比字體顏色（黑字/白字）。

### 4. 🚨 待做事件到期日前一天特殊邊框警示 (核心亮點)
- **智慧觸發判定**：
  - 當待做事件尚未完成，且基準日（今日）距離到期日**剛好剩餘 1 天（即明日到期）**時，自動啟動特殊邊框警示！
- **視覺警示效果**：
  - **記事本卡片**：呈現金橘/霓虹紅交替呼吸光暈的虛線警示邊框（`border: 2.5px dashed #f59e0b`）與 `⚠️ 明日到期！(特殊警示)` 跳動徽章。
  - **月曆格子**：在到期日當天與到期日前一天的格子中，事件標籤皆帶有高顯眼度的警示虛線外框與 `⚠️` 符號。
  - **日期模擬測試器**：頂部特別提供「基準/當前日期」選擇器，使用者或評審可隨意切換日期，即時驗證任何事項在「到期日前一天」觸發特殊邊框警示的動態效果！

### 5. 單日詳情檢視與快速排程
- 點擊月曆上的任何日期方格，會彈出該日的詳細行程浮窗。
- 自動分區列出：
  - ⚠️ **到期日前一天警示**（明日即將到期的待辦）
  - 📌 **當日排程事項**（到期待辦與提醒）
- 提供「+ 在此日新增待辦」與「+ 在此日新增提醒」快捷按鈕，自動帶入該日日期。

### 6. 本地儲存與備份機制
- 所有資料均自動保存在瀏覽器的 `localStorage` 中，重新整理或重開瀏覽器資料不丟失。
- 支援 **「📥 匯出備份」** 下載為 JSON 檔案。
- 支援 **「📤 匯入備份」** 上傳恢復先前保存的記錄。
- 支援 **「🔄 重設示範」** 一鍵載入示範資料。
- 支援 **🌙 深色模式 / ☀️ 淺色模式** 無縫切換。

## 🚀 如何開啟與使用

由於本專案採用純前端標準 HTML5、CSS3 與原生 JavaScript 開發，不需要安裝 Node.js、npm 或伺服器：

1. **直接開啟**：
   - 點擊資料夾中的 `index.html`，即可使用任意現代瀏覽器（Google Chrome、Microsoft Edge、Mozilla Firefox、Safari 等）開啟。
2. **本機伺服器（可選）**：
   - 若您習慣透過本機 HTTP 伺服器預覽，可在本目錄開啟終端機執行：
     ```bash
     python -m http.server 8080
     ```
     接著在瀏覽器造訪 `http://localhost:8080` 即可。
