# 智曆記事本 (Smart Calendar & Notepad)

一套具備**農曆萬年曆**、**待做事件管理**、**提醒事項設定**與**到期日前一天特殊邊框警示**的現代化繁體中文網頁應用程式。

* 📦 **GitHub 儲存庫**: [https://github.com/bingchiwang/smart-notepad-calendar](https://github.com/bingchiwang/smart-notepad-calendar)

---

## 🌟 主要功能特點

### 1. 雙核心架構：待做事件 vs 提醒事項
- **📋 待做事件 (To-Do Tasks)**：
  - 設定**到期日 (Due Date)** 與指定時間。
  - 支援勾選完成/未完成狀態（完成後自動加上刪除線並半透明呈現）。
  - 支援多維度即時篩選：
    - `全部待辦`：檢視所有待辦。
    - `⏳ 進行中`：過濾未完成事項。
    - `⚠️ 明日到期警示`：僅顯示剛好剩餘 1 天到期之緊急任務。
    - `📅 今日到期`：當天截止任務。
    - `🚨 已逾期`：已超過截止日任務。
    - `✅ 已完成`：已勾選完成的任務。
- **🔔 提醒事項 (Reminders)**：
  - 選擇**提醒日期 (Reminder Date)** 與提醒時間。
  - 支援分類篩選：`全部提醒`、`🔔 今日提醒`、`📅 即將到來`、`📁 過去提醒`。
- **🌐 全部視圖與即時關鍵字搜尋**：
  - 整合頁籤可同時檢視待辦與提醒。
  - 支援即時關鍵字模糊搜尋標題與詳細備註。

### 2. 完整萬年曆與農曆支援 (1900–2100)
- **純前端精準天文演算**：完全內建於 [`lunar.js`](lunar.js)，不依賴任何外部 API 或 CDN，完全支援離線使用。
- **豐富農曆與民俗節慶呈現**：
  - 每格月曆同步顯示**陽曆日期**（1～31）與**農曆日期**（初一自動標註月份名如「九月」，其餘顯示「初四」、「十五」等）。
  - **二十四節氣**（立春、清明、寒露、霜降、冬至等）以顯眼紅字自動標籤。
  - **傳統節日**（春節、除夕、元宵、端午、中秋、重陽等）與常見公曆節日（元旦、國慶日、兒童節、聖誕節等）自動標示。
  - 月曆標頭即時顯示天干地支紀年與生肖（如【丙午 馬年 · 九月】）。
  - 支援年份、月份快速下拉切換與「回到本月」功能。

### 3. 自行挑選專屬色彩 (Color Customization)
- 提供 **8 款精選高雅調色盤**：
  - 經典藍 (`#3b82f6`)、薄荷綠 (`#10b981`)、活力橘 (`#f59e0b`)、珊瑚紅 (`#ef4444`)
  - 薰衣草紫 (`#8b5cf6`)、櫻花粉 (`#ec4899`)、蒂芙藍 (`#06b6d4`)、石墨灰 (`#64748b`)
- 支援 **原生自訂色彩盤 (`<input type="color">`)**，可自由挑選任何 HEX 顏色。
- 事件放上月曆時，會以使用者挑選的專屬色彩呈現彩色膠囊標籤，演算法會根據色碼的明度（YIQ）自動計算最佳文字對比色（白字/黑字），確保極致閱讀體驗。

### 4. 🚨 待做事件到期日前一天特殊邊框警示 (核心亮點)
- **智慧差值判定機制**：
  - 當待做事件尚未完成，且基準日（今日）距離到期日**剛好剩餘 1 天（即明日到期）**時，自動啟動特殊邊框警示。
- **立體視覺警示效果**：
  - **記事本卡片**：呈現金橘與霓虹紅交替呼吸光暈的虛線警示邊框（`border: 2.5px dashed #f59e0b`）與 `⚠️ 明日到期！(特殊警示)` 動態縮放跳動徽章。
  - **月曆格子**：在到期日當天與到期日前一天的日期格子中，事件標籤皆附帶專屬警示邊框與 `⚠️` 符號。
  - **當前基準日模擬器**：頂部特別提供「基準/當前日期」選擇器，使用者或評審可隨意切換日期，即時驗證任何事項在「到期日前一天」觸發特殊邊框警示的效果！

### 5. 單日詳情檢視與快捷排程
- 點擊月曆上的任意日期方格，立即彈出該日專屬的事項詳情視窗。
- 自動分區列出：
  - ⚠️ **到期日前一天警示**（明日即將到期的待辦事項）
  - 📌 **當日排程事項**（到期待辦與當日提醒）
- 提供「+ 在此日新增待辦」與「+ 在此日新增提醒」快捷按鈕，自動帶入該日日期。

### 6. 本地離線儲存與資料備份
- 所有資料均自動保存在瀏覽器的 `localStorage` 中，重新整理或重開瀏覽器資料永不丟失。
- 支援 **「📥 匯出備份」** 下載為標準 JSON 格式檔案。
- 支援 **「📤 匯入備份」** 隨時上傳恢復先前的紀錄。
- 支援 **「🔄 重設示範」** 一鍵載入預設示範資料。
- 支援 **🌙 深色模式 / ☀️ 淺色模式**，具備主題自動記憶功能。

## 🚀 如何開啟與使用

本專案採用純前端標準技術（HTML5、CSS3、Vanilla JavaScript）打造，**無需安裝 Node.js、npm 或任何後端伺服器**：

1. **直接開啟**：
   - 在檔案總管中雙擊本目錄的 [`index.html`](index.html)，即可使用任意現代瀏覽器（Google Chrome、Microsoft Edge、Mozilla Firefox、Safari 等）開啟。
2. **透過本機 HTTP 伺服器預覽（可選）**：
   - 若您偏好使用本地 HTTP 伺服器，可在本目錄開啟終端機執行：
     ```bash
     python -m http.server 8080
     ```
     接著於瀏覽器造訪 `http://localhost:8080` 即可。

```
└── .gemini/
    └── rules/

```
